## Node engine

The production engine is bundled with esbuild and uses only Node.js 22 built-in modules at runtime. No third-party npm packages are shipped in `dist-server/index.mjs`.

## Container sidecar

`ncm-api` installs `@neteasecloudmusicapienhanced/api@4.41.1` (MIT) at image build time. It is reachable only on the internal Compose network.

## Build-time-only dependencies

Vite, TypeScript, Vitest, ESLint, Tailwind/PostCSS, `vite-plugin-*` and related tooling are dev dependencies. They are not part of the runtime image or the static site payload.
